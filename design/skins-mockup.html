Readability 5/5 5/5Flair 5/5 5/5Motion 4/5 4/5Retro 1/5 1/5

A folded mint-to-violet perimeter frames Twitch-color name chips; quiet navy backing keeps the conversation central.

Frame recipe and channel treatments

2 px gradient ring, 12 px corners, 1 px inset highlight; static 4 px scanline pitch at 3% opacity behind text. No blur dependency.

nameChip: Twitch color fill + same-color 4px static soft glow. Choose #101528 or #FFFFFF text by greater WCAG contrast; if neither reaches 4.5 adjust chip luminance minimally. Missing color #7EEAD6. Retain 1px contrasting chip edge.

badges: Original SVG crown / sword / gem / star for broadcaster / mod / VIP / sub. Highest role wins; text label accompanies icon.

broadcaster: Gold HOST tag; 600ms gold border-opacity pulse once (never text blink).

firstTime: Supplemental ✦ NEW tag on existing message, one 800ms shimmer, no duplicate body.

mentionsChannel: Violet 3px leading highlight bar independent of winning role.

action: Italic violet body independent of role; retain role tag.

emoteOnly: 2× inline size, max 56px; preserve alt text and layout bounds.

entrance: 260ms translateY(10px) scale(.96) opacity(0) → identity opacity(1); 320ms fade exit, reserve row height.

ambient: 12s mint→violet ring: translate gradient layer inside border mask, static scanlines behind text; no animated blur/filter, no per-frame JS.

readability: 94% navy backing, white body with 1px navy outline; backing stays without blur. Contrast guarantee applies to default preset, not user transparency overrides.
