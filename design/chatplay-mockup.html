Set them up myself
  1. In Twitch Creator Dashboard, open Viewer Rewards → Channel Points → Manage Rewards & Challenges. Add a custom reward.
  2. Copy a title above exactly. Swap requires a skin name; Rain requires emote codes; Chaos accepts an optional starting skin. Spotlight requires a message; Flash needs no text.
  3. Use the suggested cost and cooldown. Keep the request queue on. Leave rewards paused while setting up.
  4. Connect channel points as the channel owner and allow reading redemptions. Check each title says Matched. No creation permission needed.
  5. Replace your ordinary chat source with the private play source in OBS. Test, enable the rewards in Twitch, then redeem once and review the request.
