# Troubleshooting

Start with a fresh message and the complete link from **Get link**. Check one thing at a time.

## Chat isn't showing in OBS
1. Refresh the cache for the current Browser Source page in OBS.
2. Check that the source is sized to your canvas: **1280 · 720** or **1920 · 1080**.
3. Make sure the ChatSkins source is visible and near the top of the Sources list, above gameplay.
4. Type a new message in your Twitch chat. Test Chat is only a preview.
5. Confirm the URL is complete. Copy it again from **Get link** and replace the whole Browser Source URL; do not paste a shortened or cut-off link.

## Rewards don't show
Channel-point rewards require a Twitch Affiliate or Partner channel. In Twitch, open **Creator Dashboard > Viewer Rewards > Channel Points** and check that the ChatSkins rewards exist and are enabled. If you chose to create rewards turned off, enable them there.

## Frame looks cut off
For a side chat, choose the **tall** shape. Use **wide** for a bottom strip and **square** for a box. Check the full canvas size in OBS and avoid cropping or stretching the Browser Source.

## Emotes missing
Enable the provider you use, check the exact emote spelling, and send it as a separate word in a new message. A provider can be temporarily unavailable; the message text remains visible if an emote image cannot load.

## Old look after an update
Copy the latest link and replace the entire Browser Source URL. If the link is current but the art is stale, refresh the page cache for that source. Avoid clearing all site data first; that can remove locally saved skins.

## Still stuck
Include your streaming app, canvas size, and skin name when asking for help. Crop screenshots to the issue and remove private OBS links first.
