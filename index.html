Questions, answered

Do I need to log in?

No. Enter a channel name to make an overlay URL. Twitch sign-in is optional.

Does ChatSkins send messages to Twitch?

No. The overlay only reads Twitch chat.

Can I customize a skin?

Yes. Open Customize to use the Simple controls or Advanced editor.

How do I add it to OBS?

Add a Browser Source, paste the URL, set 1280 × 720 and layer it above your game.
